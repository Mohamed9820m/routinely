Routinely – Recurring Issues for Jira

Create Jira issues automatically every day, week or month — with reliable time zones, smart titles, due dates and full template copies.

Reliable time zones

Every schedule runs in its own time zone, so daylight saving never shifts your 9:00 report.

Flexible rules

Daily, weekdays, every N weeks, the 15th, first Monday, last working day, yearly — no cron needed.

Full template copy

Copy fields, components and sub-tasks from an existing issue, with smart titles like “Report week {week}”.

Getting started

  1. Open Apps → Routinely in Jira and click Create your first schedule.
  2. Pick a project and issue type, write a summary (tags like {date}, {week}, {month} are replaced on each run).
  3. Choose how often it repeats, the time and the time zone. The editor previews the next five runs and the next title.
  4. Save. Issues are created within five minutes of the scheduled time. Use Run now to test immediately.

Permissions

Anyone who can create issues in a project can schedule issues for it. People can edit their own schedules; Jira administrators can edit all schedules and can restrict schedule management to administrators only (Settings tab).
