Routinely – Recurring Issues for Jira

Security Policy

Last updated: 28 October 2026

Architecture

  • Runs entirely on Atlassian Forge; eligible for Runs on Atlassian (no egress).
  • No external servers, databases, credentials or API keys — the app only uses the Jira permissions you grant at install.
  • Scheduled runs act as the app; actions in the app's page are checked against the current user's Jira permissions (Create Issues in the project; owner-or-admin for editing).

Logging

Logs contain only technical information such as counts and status codes — no names, email addresses or issue contents.

Reporting a vulnerability

Email mohamedhabibmarouani8@gmail.com with the subject “Security report – Routinely”. We acknowledge reports within 2 business days and fix confirmed issues as a priority. Please don't disclose publicly before we've addressed it.

Incident response

If a security incident affects customer data, we will notify affected customers and Atlassian without undue delay, in line with the Marketplace Partner Agreement and applicable law (including GDPR).
